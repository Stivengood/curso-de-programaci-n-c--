# Sistema de control de ventas
## Descripcion 
Este programa en C++ sirve para comprar cosas en una tienda. Puedes elegir qué quieres llevar de una lista y al final te dice cuánto tienes que pagar y a la vez realiza el calculo se debe de darte el cambio o si falta dinero.
## Funciones principales
- Te muestra los productos con su precio.
- Para elejir el producto debes de elejir su numero.
- Si deseas ir a pagar aplastas la indicacion que en este caso es el cero (0).
- Te pide que ingreses tu dinero.
- Notifica si te falta dinero o te da el cambio.
## Estructura basica del proyecto
- Utilice la terminal que reconoce el c++ que en este caso es el .cpp, el nombre de mi archivo es >proyecto.cpp<.

- Entramos al visual studio code.
- Seleccionamos la carpeta numero 11.
- Abrimos el archivo >proyecto.cpp<.
- Abrirmos la terminal y copilamos el codigo.
- seleccionamos los numero segun el producto dantole enter.
- Para finalizar la compra seleccionammos el cero (0) y pagamos segun lo seleccionado anteriormente.
